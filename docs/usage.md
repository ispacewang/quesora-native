# 使用说明

Windows x64；当前项目为 MyGo 0.6.4、Go 1.27.3。纯原生界面，无 Electron、Node 或 WebView 运行时。

## 使用

双击 build/QuesoraNativePreview.exe。点击题库栏的「上传题库」，或拖入 .xlsx / .xls / .csv 文件；一次一个文件，多工作表会分别生成题库。最大 64 MiB，每张表不超过十万行。

## 自动解析题库

不要求第一行是固定模板。先扫描前 50 行定位表头，再结合表头内的解释和前面的说明识别列用途，最后将内容归一化为单选、多选、判断、填空、简答五种标准题目。

支持常见中英文别名、带括号说明的表头、双行表头、A/B/C/D 独立选项列、一个单元格内的多选项，以及题干后按行列出的带字母选项。合并选项可用竖线、换行或分号分隔。

答案支持字母、分隔的多选字母、选项实际内容、数字序号及常见判断写法。表头可说明「答案填选项编号」「索引从0开始」或「填写选项内容」。若数值既可能是序号又可能是选项内容且含义不同，会提示来源行并跳过，不会生成猜测答案。

题型可用常见名称；数字题型需在顶部或表头解释，例如「1表示单项选择，2表示多项选择，3表示判断」。缺少题型时结合选项、答案和填空标记推断。无法识别的题干/答案列、冲突或空答案、选项不足等会明确提示，不保证能理解没有语义标记的任意表格。

保留一级纲要、二级纲要、题目分类、题目依据、试题分数、试题编号、备注，以及来源工作表、行号和原始答案/题型。「是否重要」列或备注中的「重要题目／保命题」可设置重要标记。

一个有效工作表用文件名作为题库名；多个有效工作表用「文件名-工作表名」。重复名称拒绝整批导入，不覆盖现有题库。CSV 支持 UTF-8、UTF-16 BOM、GB18030/GBK。Excel 优先按文件头识别 XLSX/旧 XLS，扩展名不匹配时自动选择正确解析器并提示；原文件不改动。旧 XLS 使用本地兼容修复库；损坏或特殊文件会报告错误。

## 考试

点击顶部「考试」，选择题库、五种题型的数量和 1–180 分钟时长。按题型随机无重复抽题；题库数量不足时取现有数量。默认单选40、多选30、判断30，可自行启用填空和简答。

答题卡可跳转；疑题可标记；选择题选项打乱后保存映射。手动交卷会定位未答题，全部作答后确认判分；到期自动交卷，未答按错题处理。考试与日常练习记录分开。

重要题目答错或未答时综合成绩归零，实际答对／答错数量仍保留。结果页可回顾错题、解析，并点击「保存成绩」。顶部「我的」可展开考试记录、保存的错题本和删除记录。未保存退出会确认。

考试配置内可导出原生 PDF 试卷和答案，使用内置中文字体、自动换行和分页。同一配置窗口内的试卷、答案及随后开始的考试共用一套题序和选项顺序；修改题型数量或题库后重新组卷。复杂 LaTeX 与交互几何尚未排版还原，当前按文本输出。

## 外观与学习功能

沿用原版配色、字体及橙色软件标志；EXE 内嵌 16–256 像素图标供资源管理器与任务栏使用。

顶部标题栏和工具栏使用系统 Mica 材质，取桌面壁纸色调；顶部文字和图标采用清晰的前景色，不叠加整栏遮罩或蓝色底色。正文保持不透明。系统不支持或禁用透明效果时使用中性的主题背景。

重要题使用原版图片：切题时 750ms 转入，答对后 580ms 转出，答错保留；深色模式反色。动画停止后不持续请求刷新。满分成绩有短时原生彩纸效果。

支持题库标签切换/删除、五种题型、组合筛选、随机不重复题序、选项打乱、速刷、统计与错题侧栏、错题保存和文本导出。

刷题工具栏新增「重新作答」开关，默认关闭。开启后再次进入已答题时隐藏旧答案，允许重新作答；本次提交前保留旧记录，提交后替换该题的最近答案和统计。已保存的考试／错题本快照不变。「查看解析」仍可显示上次结果。选择自动保存在本地数据目录，重启后恢复。

统计／错题本悬浮按钮使用局部背景模糊和中性磨砂表面，文字保持清晰。窄窗口同时最多展开一个侧栏。多题库采用固定高度的横向标签栏、长名称提示和「全部题库」菜单，上传入口保持可见。

空错题本不可保存或导出；保存期间防止重复提交，切换题库或新增错题不会误显示“已保存”。考试配置显示实际抽题数和题量不足说明，无效设置在开始／导出前给出提示。「重新练习」需确认，并明确只清空全部题库的练习记录。简答沿用要点覆盖评分，Windows ICU 版本可能影响分词边界。

## 保存与隔离

安装包为当前用户安装，可自选路径；升级沿用上次路径并覆盖程序文件。同版本支持重装，较旧版本禁止降级覆盖。安装版数据独立保存在 `%LOCALAPPDATA%\QuesoraNative\data\questions.db`，升级和卸载均保留。

工程运行时数据在项目 `data/questions.db`；便携包单独运行时在 EXE 旁的 `data` 目录，也可用 `-data-dir` 指定。正常启动从空题库或已保存的本地题库开始。若安装到旧便携目录，且用户数据目录没有数据库，首次启动会一致性快照迁移程序旁的旧数据库并保留原文件；已有目标库不覆盖，不扫描其他目录。

顶部「设置」提供主题与练习模式、数据目录和「备份全部数据」。备份包含题库、答题记录、已保存的考试/错题本、学习设置，包含已提交的 WAL 数据。备份完成并校验后才替换同名备份；失败保留原备份。点击「从备份恢复…」并确认后，会校验原生数据库、自动在当前数据目录的 `backups` 中保存 `before-restore-*.db`，再事务替换题库、答题、历史和学习设置。校验/写入失败会保留当前数据或回滚；不支持 Electron 数据库或任意 SQLite 文件。恢复期间请等待完成。

主题、随机/速刷/打乱、侧栏、题库筛选及当前题目会自动保存。重新打开后按题目 ID 恢复位置；随机题序会重新生成。未交卷的考试尚不能跨重启续考。

原生版使用独立数据库，不会自动读取、转换或覆盖 Electron 版的数据。删除题库不删除原始 Excel 文件。

## 构建和当前边界

运行 python build-preview.py：隔离构建、Go 测试、MyGo vet、Windows 图标/高 DPI 清单检查、EXE 和便携 ZIP、离屏场景预览。构建需要 Go 和 Python，成品不依赖 Python。

本批只执行自动化检查；真实窗口、Mica、文件选择/拖放、中文输入、视觉一致性和实际内存由用户验收。完整 1:1 尚未完成：AI 配置/生成、通用 LaTeX、交互几何、导入预览/列映射、跨重启续考等仍在迁移。PDF 的复杂公式/图形排版也未完成。

third_party/xls 是 Apache-2.0 本地兼容修复副本，见 QUESORA_CHANGES.md；便携包保留字体及依赖许可证。

题库标签栏支持鼠标滚轮横向浏览；标题栏显示原生预览版本号。顶部已隐藏 AI 入口，「我的」从标题栏下方展开。「随机／速刷／打乱」支持悬停查看说明。

## 程序内更新

「设置 → 软件更新 → 检查更新」只访问官方 ispacewang/quesora-native 的公开 Releases。预览版检查更高的预览/正式版，正式版只检查正式版，不建议降级。没有启动时自动联网或后台静默安装。

找到可用 Windows 安装包后，点击「下载安装包」；可查看进度或取消。校验官方 SHA-256 成功后才显示「安装更新…」。确认后再次复核安装包，在当前数据目录自动创建 `backups/before-update-*.db`，然后关闭程序并打开安装向导。安装版沿用原安装位置，完成后可启动新版。备份/校验失败不会启动安装器。

便携运行也可下载安装包，但安装器创建的是安装版，不替换便携副本；安装后可从更新前的备份恢复数据。若继续使用便携方式，请打开「发布页面」下载 ZIP，替换程序文件时保留 data 目录。

网络失败、GitHub 限流和未完整上传的发布不能视为“已是最新版”。遇限流会显示服务端重试时间并阻止立即重复请求，也可手动打开发布页面下载；程序不保存/要求 GitHub Token。

## 图标与维护

新图标按用户参考制作橙色圆角矩形题卡/Q 气泡，透明边界由 qa/icons 导出规范固定，Windows/标题栏/安装器使用同一设计。源码注释、数据所有权和开发流程见 [维护导览](development.md)。

## 外观与 AI Beta

「设置 → 外观」提供跟随系统、浅色和深色三项，顶栏不再单独切换主题。

AI Beta 默认关闭，在「设置 → AI 功能（Beta）」显式启用。开启后出现顶栏 AI 助手、单题 AI 复核和统计诊断入口；关闭取消任务并隐藏入口。五厂商配置、参考资料范围、计费边界及判题规则见 [AI 使用说明](ai.md)。

预览版更新检查优先读取本仓库的官方 Release 订阅源；不可用时尝试 GitHub API。正式版通道使用 API 核实预发布标记。连续点击会复用最近一分钟的成功结果，提示可再次刷新的时间。服务端限流时遵守重试时间，也可直接打开发布页面下载安装包覆盖升级。文件长度确认、SHA-256 校验和安装前备份仍保留。
