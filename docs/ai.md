# AI 助手（Beta）

AI 是可选实验功能，默认关闭。到「设置 → AI 功能（Beta）」开启后，顶栏、题卡和统计侧栏才显示 AI 入口。关闭会取消未完成请求、清除未保存预览和当前资料；已有题库与学习记录保留。关闭不删除已存密钥，可在配置页单独删除。

## 配置服务商

先在设置中打开「配置服务商」，选择品牌图标，填写该厂商的 API Key 和已开通的模型，保存配置。每家配置独立保存，切换品牌不会把一家密钥发送给另一家。测试连接是一条真实的短请求，可能计费；不开启 Beta 时不会发送测试请求。

| 服务商 | 默认地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | https://api.deepseek.com | deepseek-flash |
| OpenAI | https://api.openai.com/v1 | gpt-4.1-mini |
| 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
| 智谱 GLM | https://open.bigmodel.cn/api/paas/v4 | glm-5.3 |
| 豆包 | https://ark.cn-beijing.volces.com/api/v3 | doubao-seed-2-1-pro-260628 |

模型可手动修改，以账号已开通权限为准。千问可改为对应地域或业务空间专属的官方地址；豆包也可填写自定义推理接入点 ID（ep- 开头）。仅支持这五家官方 HTTPS 服务，不接受第三方代理地址，不跟随认证请求重定向。订阅聊天产品或 Coding 套餐不必然包含通用 API 的余额/权限。

密钥所在的 ai-settings.bin 使用 Windows 当前用户的 DPAPI 加密，位于当前数据目录。它独立于 SQLite，不进入题库备份，也不随 EXE/ZIP/安装包分发。换电脑、Windows 账号或重装系统后可能需要重新填写。不会自动读取 Electron 版的明文配置。

## 出题与参考资料

在出题页通过下拉框选择五家服务商之一；选项显示已配置/未配置，下方显示当前模型和配置状态，“配置此服务商”可进入对应编辑页。请求使用当前选择的独立 Key 和模型，不会默默回退到 DeepSeek。出题页切换只影响当前会话的服务商（判题/诊断也使用当前服务商）；需要记住默认项时保存该厂商配置。

填写新题库名、主题和 1–500 的题量；可选参考资料。支持 TXT、Markdown、CSV、Excel（XLSX/XLS）、DOCX 和可提取文字的 PDF，全部在本地用 Go 解析，无 Python/markitdown/WebView。单文件最大 16 MiB、正文最多 60000 字、PDF 最多 200 页。扫描 PDF 需先 OCR；图片、音视频和加密/损坏资料不支持。

点击「生成预览」才会发送主题及资料文本。长资料按每批最多 4000 字分段轮用，生成多批题目；小题量不保证覆盖整份长资料。一次只处理一个附件，可在发送前编辑提取出的正文。模型生成五种题型，使用纯文本和可读数学符号。后续批次会带上已有题目的受限摘要以减少跨批重复。

生成只保留在内存，逐题检查题干、选项、答案和解析后再「保存为题库」。确认后整体事务入库，重名或保存失败不会覆盖已有题库。同批和跨批重复题会自动过滤，保留有效题目供预览，并明确提示请求数量、重复数量和实际保留数量；去重可能导致题量少于输入值，不会自动追加付费请求补齐。查重结合题型、题干和选项集合，避免把“下列哪个正确”等相同题干但选项不同的题误删；更换选项顺序、答案或解析不会绕过去重。返回格式错误、答案越界或任一批请求失败仍会明确报错，不会自动入库。取消/关闭会使迟到响应失效，已由厂商处理的请求仍可能计费。

## 判题与诊断

默认提交仍使用本地规则。开启「提交时使用 AI 判题」并保存配置后，日常练习提交会发送本题和作答给模型；请求失败保留输入，不会悄悄改用本地判题。等待期间可取消，切题也会取消待处理结果。考试评分继续使用本地标准答案，不受 AI 设置影响。

已提交的题目可「AI 复核本题」。复核显示理由，只有点击「应用到练习记录」才更新该题正确/错误状态及 AI 说明，原标准答案不变。作答或题目变化后，旧复核不能直接应用。

「AI 薄弱点诊断」仅发送当前题库名和各题型正确/错误统计，不发送完整题库。诊断是参考建议，不是考试成绩。

## 当前边界与验证

Beta 不保证生成知识或判题意见始终正确。真实计费、模型权限、网络可达性由各厂商和账号决定。开发回归使用 HTTP 替身验证五厂商协议、密钥隔离、取消、格式检查和入库流程；没有使用个人密钥执行五家付费联调，须在自己的账号下用「测试连接」和少量题目验收。
